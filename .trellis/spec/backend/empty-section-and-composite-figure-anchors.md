# 空白分节与组合图的规则及批注定位契约

## 1. 范围与触发

适用于 `PAGE-01` 页边距结果锚在含 `sectPr` 的空分节，以及图片后续段落由 VML 文本框、组合图形或独立题注组成时的图片识别。规则检查、图像解析和 Word 批注写入各保留自己的职责；不能通过略过真实错误或把图内文字拼成题注来消除未写入状态。

## 2. 接口与事实来源

- `ImageParser.parse(byte[] xml, ...) → List<ImageModel>`：以原始 OOXML 对象及 `SourceAddress` 为事实；`w:drawing` 图片与含实际媒体引用的 VML 图片可建模，仅有 `v:imagedata` 空壳的纯组合形状不算媒体图片。支持 `r:id`、`o:relid` 和 `src` 证据。
- `ImageModel.captionSource`：必须指向实际图题文字所在的段落；文本框题注使用该框内部 `w:p` 的路径与真实字符范围，不得使用外层无正文文字段落加总内部字符长度。`captionFragment`、`captionNumberAmbiguous`、`ambiguousCaptionChapters` 是内部规则证据，`@JsonIgnore` 保持既有审核 JSON 图片字段形状。
- `ImageRuleChecker`、`AppendixRuleModule`：只在图号唯一可证时硬检查引用与编号；题注分散或多候选时按可确认程度输出 `REVIEW`。`DocumentRegionClassifier.isFigureReferencedInBody` 从题注源地址找到最深的非文本框外层段落，只排除同组图形内其他文本框的伪引用；不同外层段落的独立正文文本框仍可提供引用证据。表引用入口维持原语义。
- `CommentWriter.writeCopy(...)`：输入是原稿、目标副本、源哈希和检查结果。仅对来自 `word/document.xml` 且真实带 `sectPr` 的 `PAGE-01` 使用同节空段落的零宽批注锚点；若同节有普通正文，仍优先定位同节正文。支持 Transitional 与 Strict WordprocessingML 命名空间。

## 3. 数据流与不变量

`DOCX XML → 分节/图对象和独立题注段落 → PAGE/FIG/APP 检查结果 → 原始 SourceAddress → 写入副本 → 每项 AnnotationStatus`。同一外层段落内多个 `w:txbxContent` 不能当作一个连续文字范围。多个图号候选不能任取首项当确定事实，也不能借它硬查字体、字号、顺序或引用。一次歧义图号影响同章后续顺序时，后续序列给 `REVIEW`；其他章/附录保持硬检查。

批注源地址在删除旧系统批注前解析并校验。零宽批注只在已有空段落写标记和引用 run，不插入可见占位符、不新建段落、不改 `pPr/sectPr` 或媒体。批注如果写到文本框内部，比较图形不变性时只排除本次新增的批注标记、引用 run 及预期标示，其他 VML 形状属性和原有文字必须一致。

## 4. 错误矩阵

| 证据 | 结果 |
| --- | --- |
| `PAGE-01` 的所属分节有可标注正文 | 继续原有同节文字定位 |
| `PAGE-01` 的所属分节仅有现存空段落 | 在该节空段落写零宽批注；四边结果仍各自报告 |
| 没有现存且安全的同节段落 | 保留 `UNSUPPORTED_ANCHOR/EMPTY_ANCHOR`，不能借前后节 |
| VML 仅有无媒体关系的组合形状 | 不另建伪图片或伪“缺图题”结果 |
| 一个完整题注位于独立段落或单个文本框 | 使用真实段落路径，按原格式规则检查 |
| 图号单独在一个文本框，其他框是图内标签/来源 | 保留唯一图号的编号与正文引用检查；完整题注、位置无法从 XML 确认时输出 `REVIEW` |
| 多个可疑图题/图号文本框 | 保留内部合法锚点，图号、字体字号、位置及受影响序列输出 `REVIEW`，不拼接、不硬判 |
| 题注末尾为普通/全角/窄/零宽空白 | 与既有图号识别使用同一空白分类，不把只有图号的片段误判为完整图题 |

## 5. 正例与反例

正例：空白分节含两个现有空段落，节末 `sectPr` 的四边错误仍产生四个结果，批注可合并显示于该节空段落而四项状态均为 `WRITTEN`。图 `w:drawing` 后是独立完整的“图4-1 标题”，`captionSource` 指向该段，格式和引用继续硬查。

反例：图后一个 VML 组合段落的三个文本框依次为“图4-1”、图内百分比、资料来源；递归拼成 152 字并锚外层空文字段会产生 `SOURCE_RANGE_OUT_OF_BOUNDS`，也会把无媒体引用的两个形状误算成图片。

## 6. 必需测试

- `CommentWriterTest`：五个空白分节的 20 项四边结果、文末空节、夹在正文间的空节、普通空段落负例、Strict 分节及 Strict 文本框排除；断言批注在本节、无可见文字或属性变化。
- `ImageParserTest`：真实图片与三个文本框、完整单框题注、多候选歧义、VML 有/无媒体引用、零宽尾空白；断言图像数、内部源路径和文字范围。
- `ImageRuleModuleTest`、`AppendixRuleModuleTest`、`DocumentRegionClassifierTest`：唯一图号引用、同组图内同号假引用与独立正文文本框真引用、歧义本张与同章/同附录后继序列、其它章节严格检查。
- 审核 JSON 序列化回归：内部图像证据字段不扩展现有公开图片字段。
- 真实 DOCX：核对输入哈希、所有应选批注状态、ZIP 可读、原文、分节/段落/表格属性、图形和媒体不变；不得把 XML 检查冒充 Word/WPS 最终视觉分页验证。

## 7. 错误与正确做法

错误：把空白节的页边距问题移到下一节文字、给空段落插可见空格、把多个文本框全部 `w:t` 递归拼成普通图题、只要出现 `v:imagedata` 就算媒体图片，或在歧义图号后继续硬报跳号。

正确：守住同节空段落和独立文本框的源地址边界；用真实媒体关系识别图片；仅根据唯一且充分的题注证据做硬检查，剩余不确定性明确给 `REVIEW`。

## 8. 标题下空白行的批注表达

- `HEAD-02-BLANK-FONT/SIZE` 先明确“本条检查标题下方的空白行，不是标题文字”，再说明原位置、空白行实际属性与所需属性。显示在正确标题旁不能成为判断该标题字体错误的证据。
- 字体和字号仅在原 `source` 与 `contextSource` 均相同时合并一次位置说明；同页首的不同原空白行分别保留位置与实际属性，所有规则结果及批注状态仍逐项保留。
- 操作建议针对检查对象：独立空段落提示选中整个空白行，包括其中的空格、换行标记和段落标记，避免仅改段落标记而保留空格自身的错误格式；同段手动换行形成的空白行提示选中对应换行标记及空格。不能提示用户修改附近标题文字。
- 不根据空白行问题宣称标题全部正确；标题本身若有字体、字号错误，仍由相应标题规则独立检查、批注。合规空白行不产生错误，未知属性保留“未能读取、请确认”，不得虚构当前字体或字号。
- 必需回归：正常标题与错误空白行、两者同时有错、只错字体或只错字号、完全合规、未知属性、同页首多个原空白行、手动换行，以及写入/重复检测后原稿内容与格式不变。
