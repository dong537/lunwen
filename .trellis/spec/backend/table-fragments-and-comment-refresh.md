# 拆表证据与重复批注契约

## 范围与触发
同一张视觉表可能拆成多个物理 `w:tbl`。重检的输入可能已经含本系统批注。解析、规则、批注三层必须分别处理物理事实、逻辑关系和输出副本，不能凭同列数合表或无条件删除全部旧标记。

## 签名与事实来源
- `TableParser.parse(...)` 产出物理 `TableModel`；`topBorder/middleBorder/bottomBorder` 只代表当前物理表的有效边框，不改写为邻表值。
- `TableModel.fragmentEvidence()` 为可空的只读关系证据，含 `originalSource`、`continuationSource` 和 `DATA_ROW/REPEATED_HEADER` 类型；旧构造器默认无证据。
- `TableRuleModule` 只据明确 `DATA_ROW` 证据从真实尾片段读取底线；`TableRuleChecker` 和附录对象编号使用同一证据，不另行凭物理表列表回退两项猜关系。
- `CommentWriter.writeCopy(source, target, expectedSourceSha256, results, replies)` 只写输出副本。检测的 `SourceAddress` 是原始 DOM 的元素路径；新旧批注移除前必须完成所有定位、范围校验与页首回退引用捕获。

## 数据与配置契约
显式续表的三段数据尾片段关联至少要求同一容器相邻、合法完整且精确一致的列网格、同号续表、原续表头一致和无独立表题。独立重复表头必须与原表头一致，允许重复同号表题；后续纯数据块不必再重复表头，由已证实的独立表头提供证据。中间只允许已核验的空段及无内容布局标记；正文、图片/图形/公式/对象、分节、复杂域和修订边界阻断关联。无关联证据不等于可免检。

无显式续表编号的双段浮动数据片段采用独立判据：同一容器中相邻，原段有完整表题、表头及数据且未以底线闭合，后段没有独立表题、顶线或表头分隔线；两段的浮动锚点、纵向定位、表格样式、布局及相关表属性一致；表格宽度分别与自身合法列网格相等，并且水平定位加每一列的累计宽度所得右边界逐一精确相等。只允许起点和首列宽度互相抵消的精确位置差异，不设 twips 容差，不凭同列数或同样式合并。显式不同表题、中间正文或对象、任一列边界不同、原段有底线或尾段有顶线时保持独立检查。此类片段的 continuationSource 为空，不得借给后续任何续表；只有显式且来源匹配的 continuationSource 才参与续表表头判断。

原表的表题也可能写在表内第一行：当首行唯一单元格横跨列网格、仅有一段非空表题文字时，解析器将该段绑定为表题来源，并从下一行开始寻找真实表头。不得把表内表题当作列标题与续表比较。重复表头的文字证据独立于可选的 `w:tblHeader` 标记；无标记但实际重复的表头仍须按内容比较，真正不同的表头继续报警。表题来源保留原 XML 段落路径，供批注和格式检查使用。

原片段负责顶线与表头下横线；数据尾片段负责真实底线。单元格显式 `nil/none` 仍优先，不使用表级线覆盖，也不增加几何容差。数据片段保留单位、重复文字与表注检查；重复表头不得因为自身没有数据而新增缺单位误报。

## 验证与错误矩阵
| 情况 | 行为 |
| --- | --- |
| 已证实数据尾片段且真实底线存在 | 不报原片段缺底线或尾片段缺表题 |
| 尾片段缺底线/部分单元格缺底线 | `TAB-02` 失败，定位真实尾片段 |
| 被使用的样式边框未知 | 保留 `TABLE_BORDER_EVIDENCE_UNRESOLVED`，不可冒充通过 |
| 不同编号/表头/网格或有中间对象 | 不建立关联，独立原有规则继续执行 |
| 双段浮动片段的列右边界逐一精确吻合且边线连续 | 后段作为数据尾片段，原段借用后段真实底线；前段顶线和表头线仍由前段负责 |
| 双段关系后出现不相关的同号续表 | 不借用无显式续表来源的双段证据，按原有续表规则独立检查 |
| 无实际独立表题的附录片段 | 不单独要求附录表号，保留内容检查 |
| 独立旧系统批注、无人工讨论 | 刷新批注本体、story锚点与对应现代元数据 |
| 人工批注、有人工回复的系统线程或本次显式回复目标 | 保留整个相关线程 |
| 高亮来源不明 | 保留，既不猜颜色归属，也不无条件覆盖 |
| 本次无新错误但已移除旧系统批注 | 仍生成完成刷新的文档副本 |

现代批注清理沿 `commentId → paraId → durableId` 同步处理标准 `commentsExtensible.xml` 直接条目；人工讨论、显式回复目标、共享 durableId 和未知命名空间/条目保留。未改变的扩展部件保持原字节，不整体删除部件或关系。

## 正常与异常示例
正常：原表无底线、空段、无题尾行有底线、同号同表头续表，关联后检查真正末行。异常：原表缺底线，后面另一独立一行表恰好同列数，不能借其底线把原表判为合规。

## 必需测试
通过真实 XML/ZIP 与正式规则入口覆盖片段有线/缺线、部分缺线、跨正文/对象/节边界、不同表号/网格/表头、重复表头单位证据、片段全部数据行的内容检查与附录编号。双段浮动片段另外覆盖精确列右边界、定位/样式差异、独立表题、已闭合原段和后续无关续表反例。批注覆盖人工、人工回复、明确回复目标、多锚点路径、modern metadata、无新问题清理和未知来源高亮。实稿验收记录输入摘要、目标错误变化与原文/格式/媒体不变；历史基线不可替代本次全量 Maven 验证。

## 错误与正确做法
错误：把物理片段 `continue` 整张跳过，或恢复表级边框 OR 单元格边框以压掉错误。

正确：保存物理事实，仅在结构证据成立时关联，按实际位置检查对应边线，同时保留片段内容规则。
