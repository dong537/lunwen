## 可沉淀的长期契约

- 会话拥有者负责在任何身份来源变化时清理用户缓存，不能只处理本页登录/退出。账号切换必须同步清理页面 File/编辑 state。
- mutation 的后台任务与页面响应分离；离开页面或切换用户后不得由迟到响应写回私有缓存或强制导航。
- 声明式路由守卫依赖服务端会话，改密后的导航必须等待新的会话状态。
- 错误 envelope 使用 `fieldErrors`（当前 Java record 实际字段名）；前端必须保留中文字段原因，不仅显示总提示。

以上记录供主 Agent 更新平台 spec；本 Agent 未越界修改其它 spec 或服务源码。
