# 引文上标与参考文献校验

## 目标

按学校 CITE-01、REF-03 检查正文数字方括号引用的上标样式、正文引用与文末条目对应关系，以及条目是否按首次引用顺序排列。正文引用格式问题以段落为批注锚点，同一段落多处引用只报告一次。

## 数据流

`word/document.xml` → docx4j 解析有效 run 样式 → `RunModel.verticalAlignment` 保存 `w:vertAlign` → `RuleEngine` 在正文范围解析引文并比对 `ParsedDocument.references` → `CheckResult` 由 `CommentWriter` 写入段落批注。

`RunModel` 保留 `null` 表示 XML 未提供垂直对齐属性；对引文而言，这代表没有证据证明它是上标，因此判为格式不符合。字体或字号缺失时标为需复核。引用编号可跨 run，按段落字符区间检查每个参与 run。

## 当前判定

- `CITE-01`：数字方括号编号需为小四（24 半磅）、Times New Roman、上标；一个段落内合并为一条结果。
- `REF-03`：解析 `[n]`、`[n,m]`、`[n-m]`、`[n][m]`；每个正文引用必须有条目，每条文末条目必须被引用，条目顺序需与编号首次出现顺序一致。
- 引用范围按文末实际编号条目数限制展开；范围降序、超出条目数、编号格式异常或分隔符不支持时直接判为不匹配，并暂缓双向引用结论，避免级联报出“文献未引用”。
- 编号以字符串为键并保持首次出现顺序；重复引用不重复计入顺序。

## 验证与边界

自动化用例覆盖 XML 上标读取、未上标引用、参考文献区编号排除、跨 run 引用、组合编号、超过旧 1000 编号上限的有效范围、超出实际文献条目数的范围、空格与不换行空格、顺序错误和未引用条目。真实论文文件未包含在当前仓库，须在可用真实文件时复验批注锚点和实际判定数量。

当前仅处理 `word/document.xml` 正文中数字方括号引用；脚注/尾注、域生成引用、作者-年份引用、非数字上标及无法识别的引用语义不在自动判定范围。Word 最终视觉位置（是否落在所引内容末句右上角）仍需排版渲染或人工复核。

参考文献区域从“参考文献/References”标题开始，在“致谢/Acknowledgements”或“附录/Appendix”标题处结束；后续章节中的方括号编号不再作为参考文献条目。标题匹配仍依赖这些可识别名称，其他自定义章节标题需复核。
## 引文候选边界

为避免把正文中的普通编号误认为文献引用，引用候选仍要求数字方括号结构；括号内出现空格（含 Unicode 空格）会使 CITE-01 判为格式错误。组合分隔符或编号范围无法按支持语法解释时，REF-03 直接判为范围不匹配，并跳过同一文档的双向引用/未引用级联判断。有效范围按参考文献实际条目数限制，不使用任意固定上限。引用编号的位置不强制卡在句末标点之前。

## 期刊页码序列

页码解析支持冒号后的页码范围，并将 `+` 连接的补充页保留为同一个页码值，例如 `83-85+89`、`144-146+150`。逗号引出的在线优先期刊页码仅接受明确的页码范围，避免把出版年份误识别为页码；确实缺少页码的期刊条目仍由 `REF-04` 报错。
