# 目录缩进兼容修复

目录二、三级条目不再因缺少“整体左缩进 2/4 字符”被判错。该要求是此前从“不检查目录首行缩进”错误推导出的附加要求，不能用它要求作者修改论文。

| 场景 | 当前行为 |
| --- | --- |
| 二级目录首行缩进 2 字符，未设整体左缩进 | 兼容，不产生目录缩进错误 |
| 三级目录首行缩进 4 字符，未设整体左缩进 | 兼容，不产生目录缩进错误 |
| 使用整体左缩进，或未设置缩进 | 不增加新的二、三级缩进硬要求 |
| 一级目录 | 保留既有顶格检查 |
| 目录字体、字号、行距、编号空格、数字页码、标题对应 | 继续独立检查 |
| 正文及正文标题 | 保留原有首行缩进规则 |

`ContentsRuleChecker` 只对明确的一级目录执行 `TOC-ENTRY-INDENT`。二、三级不产出该项结果，不把“没有执行”写成“检查通过”。首行缩进与整体左缩进仍由解析器独立读取，没有换算替代、放宽容差或针对单篇论文的例外。

缩进适用范围优先读取目录样式级别；编号内部夹空格时仍识别其层级，空格错误另行报告。无法确定层级的条目不再默认一级。目录和标题模块在目录区域内共用手工二、三级条目的识别证据，避免缺页码、非数字页码和编号空白问题使目录同时进入正文标题检查。该弱证据没有扩大为全局目录豁免，真正正文三级标题仍按原规则检查。

批注建议与规则覆盖说明已同步删除“二级必须整体左 2、三级必须整体左 4”的要求。2026-10-18 的旧实施记录已增加更正标记。

验证先复现旧规则失败，再验证修复：

- 直接字符/距离属性、样式继承、中文目录样式名及无缩进的 DOCX 回归。
- 编号含多余空白且缺页码或页码为字母的组合场景，仍报空格/页码错误，不误套正文标题规则。
- 回读实际生成的 Word 批注，确认同条目的字体、字号、行距、空格和页码问题仍被写入，且没有目录缩进误导。
- 定向测试 490 项通过；引擎 `rtk mvn -q verify` 全量 1,244 项通过，59 个测试类，0 失败、0 错误、0 跳过。

测试证据位于本地 `artifacts/toc-indent-compatibility/`。本次没有修改论文内容、重新生成 16 篇批注文件或部署服务，因此旧 Word 文件中的批注不会自行消失。跨段复杂目录域的完整状态跟踪属于既有解析边界，本次没有扩展解析器。
