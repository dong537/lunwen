# 附录可选规则

按 2026-10-19 用户最新要求，附录是可选章节，替代此前“每篇必须有附录”的决定。

| 论文情况 | 检查行为 |
| --- | --- |
| 正文后无实际附录 | 不报缺附录，不要求目录补附录，不产生附录格式问题 |
| 有实际附录 | 继续查标题字体字号、空格、对齐、空行、分页证据、字母顺序及图表公式编号；目录需列出附录及页码 |
| 已有总标题，缺字母分项 | 具体提示缺少“附录A”等分项，不能泛称整篇缺附录 |
| 已有字母分项，缺总标题 | 提示在分项前补“附    录”总标题 |
| 目录虚列附录 | 继续报告目录与正文标题不对应 |
| 目录附录条目缺页码 | 按目录页码问题处理，不当作实际附录标题 |
| 正文、表格或文本框提到附录 | 不能据此认定存在实际附录章节 |

目录、标题与附录模块共用区域证据，包含无目录样式的手工条目。只有在目录区域内才使用目录排版弱证据；明确的标题样式、大纲和自动编号优先，不能因真实附录字体错误而停止检查。报告和规则覆盖清单同步说明附录可选；没有附录结果不表示检查通过。

回归入口为 `OptionalAppendixPolicyTest`，通过实际 DOCX/XML 解析及 `RuleEngine` 验证适用范围，并保留已有附录格式、编号、目录、正文和批注回归。验证命令和结果见本任务检查记录。
