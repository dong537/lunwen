# 三线表边框位置判定

## 目标

修正单元格边框位置误判：不能因任意单元格存在 `top` 或 `bottom` 边框，就认定整张表的顶线或底线存在。

## 判定方式

- 顶线：表级 `tblBorders.top`，或第一行单元格 `tcBorders.top`。
- 中线：表级 `insideH`、单元格 `insideH`，或非末行的 `bottom` / 非首行的 `top`。
- 底线：表级 `tblBorders.bottom`，或末行单元格 `tcBorders.bottom`。
- 竖线：仍检查表级和单元格级 `left`、`right`、`insideV`。
- `nil` 与 `none` 表示无边框。

单元格边框按所属表格和行筛选，嵌套表格不会作为外层表格的证据。

## 验证与边界

测试覆盖表级边框、单元格级边框、边框位置错置、嵌套表格及表题顺序。Word 表格样式继承、条件格式及最终线宽、连续性和跨页视觉效果仍未纳入自动判定；读取不到直接 XML 边框时仍需后续以样式解析区分“无边框”与“证据不足”。
