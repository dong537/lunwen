# Visio 图题漏检与正文字号误报修复

## 目标与范围

图题按五号宋体检查；图号和图题之间要求一个普通空格。修复未识别的 Visio 图片导致题注漏检且被当正文要求小四的问题。此次不更改学校字号规则、不按论文名或图号设置例外、不部署和批量重跑论文。

## 根因与数据流

真实论文的图片位于 `word/document.xml` 的 `[0,198]`，采用 `w:object > v:shape > v:imagedata`，没有 `w:pict` 包装。旧 ImageParser 只识别 drawing/pict，遗漏图片和紧邻题注绑定。BodyFormatRuleChecker 从解析结果获取题注位置，因缺少绑定而对 `[0,199]` 套用正文规则。

题注三个 run 为“图”“3-4”“登录时序图”，字号均为21半磅，即10.5磅（五号），图号后确无空格。旧批注40要求改小四，属于系统误报。

权威数据流：DOCX原始XML → ImageParser识别图片并绑定题注 → ParsedDocument.images → 图题规则检查空格/五号/宋体，正文模块排除绑定的题注 → CommentWriter写入具体修改建议。

## 修改边界

- 图片解析层支持直接 VML OLE 图片，复用公式预览排除判断，避免把公式当成插图。
- 带 pict/drawing 的已有包装只计一次；无文字 object 也作为题注绑定边界，避免前一图片抢题注。
- 整链回归检查：三段 run 的五号宋体题注不再产生正文格式问题；缺空格/多空格产生具体批注；单空格通过；错误字体字号仍须报错；正文仍要求小四。
- 交付论文副本仅补图3-4题注空格并清理该处旧错误批注及专属高亮，保留原件和其余内容。
