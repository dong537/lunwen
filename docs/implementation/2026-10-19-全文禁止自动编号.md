# 全文禁止自动编号

本次按用户明确确认，论文的内容编号须手动输入。标题、参考文献、正文列表，以及由自动序号生成的图表和公式编号都纳入检查。此要求来自本次用户补充规则，不把它标成学校原文条款。

## 检查与提示

| 情况 | 结果 |
| --- | --- |
| Word/WPS 编号或多级列表，包括样式继承 | 自动编号错误 |
| 图表等自动序号、行内列表编号 | 自动编号错误 |
| 手工输入的序号 | 不报自动编号，继续检查空格、格式和顺序 |
| 只有项目符号或已取消的编号设置 | 不按自动数字编号报错 |
| 编号定义残缺或存在冲突 | 无法确认，在报告中说明 |
| 页码、自动目录、交叉引用 | 继续按各自原有规则检查 |

批注直接说明取消当前段的编号或多级列表后手动输入原序号。自动序号则只转换当前序号，不要求全文取消字段。参考文献编号后保留一个普通空格；一级标题序数后两个普通空格，二、三级后一个。

## 实现边界

原始 DOCX → `AutomaticNumberingParser` → `ParsedDocument.automaticNumbering` → `AutomaticNumberingRuleModule` → `NUMBERING-01` → 中文报告及 Word 批注。原有生成编号解析继续用于章节归属、连续性和引用核对。

主文档包含表格和文本框；页眉、页脚、脚注、尾注只扫描实际使用的部件。生成列表标签没有对应的正文文字，批注使用当前段首定位，避免虚构字符范围和整段高亮。同一段相同类型的自动编号合并提示。

报告保留待确认结果。现有账号平台的问题数量仅统计错误，尚未单独展示待确认数量；不能依据平台零问题数量推断所有规则均已确认。没有可标注内容等定位失败仍由批注对账列出原因。
