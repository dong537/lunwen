# 封面页眉与目录章号空格修正

## 本次目标与范围

按用户 2026-10-18 最新明确要求修改通用规则：封面不要求页眉；目录中的一级章号（例如“第一章”）与标题之间使用两个普通空格。摘要至附录的页眉内容、字体、字号、对齐继续检查；目录二、三级编号后仍为一个空格。目录左侧两字符缩进与编号后空格分别检查。

只调整对应规则、批注文案、报告覆盖说明和回归测试，不改论文本身的格式，不进行无关规则迁移。
