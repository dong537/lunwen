# 带格式要求标签版规范逐条审计

## 2026-10-09 真实论文规则复筛修正

- `BODY-INDENT`、`ABSTRACT-INDENT` 和标题缩进只有在 XML 提供 `firstLineChars` 或 `firstLine` 数值时才输出结果；没有缩进证据时不生成错误，也不写批注。
- 表格内段落不参与章节标题、正文缩进和章节空行状态机，避免单元格中的“3.1 测试步骤”被当成论文标题。
- `TAB-04` 只适用于表头明确表达测量值、数量、误差、温度、电压、合格率等定量字段的表格；“项目/内容”“步骤/预期结果”等说明性表格不要求单位。

- 进一步增加程序清单识别：包含 `if/return/void` 等代码关键词并带有代码符号的段落不再套用正文首行缩进；真实论文复筛中 `BODY-INDENT` 从 89 条降为 74 条。
- 表格引用增加“如表3-1所示”“见表 3-1”“参见表3-1”等具体编号表达；没有具体表号的“相关表格”不视为引用，真实论文的 19 条 `TABLE_NOT_CITED_IN_BODY` 因此保留为待修改问题。

审计对象：`学校论文规范（有格式要求标签版）(1).docx`

审计方式：读取 `word/document.xml`、段落属性、字符属性和当前 `school-v1` 规则实现；将说明文字、示例文字和规则样例分开判断。

## 先说结论

这份文件不是一篇可直接检测的普通论文。它把规则说明、正确示例、错误示例和示范论文内容放在同一个 DOCX 中。直接上传它会把“黑体、三号、空一行”等说明段落当成论文正文，当前实测会得到 954 条结果，其中 232 条错误；这些错误不能作为系统准确率依据。

本次审计后已先补上 `END-01-LINE`：致谢/附录一级标题现在检查 1.5 倍行距，并在批注中给出“致谢标题行距应为 1.5 倍”的修改建议。

真正需要补齐的学校规则有 8 项，当前实现存在 4 项过严检查，另有 4 项只能依赖排版引擎或人工证据，不能从 DOCX XML 直接下结论。

## 已覆盖且有明确依据的规则

- 四边页边距 2.6 cm（1474 twips）。
- 封面论文名称、学生信息、日期的字体、字号和加粗。
- 中文摘要、英文摘要的标题、字体、字号、首行缩进、1.5 倍行距和标题后空行。
- 中文关键词数量、分号、末尾标点、标签加粗。
- 目录标题、一级/二级/三级标题的字体、字号、居中、编号后空格和首行缩进。
- 正文宋体、小四号、英文和数字 Times New Roman、首行缩进 2 字符。
- 章节标题与正文之间空一行。
- 公式编号、章节序号、重复编号和正文引用。
- 图题、表题存在性、上下位置、编号格式和正文引用。
- 参考文献类型标识、编号连续性、作者/题名/来源/年份字段和正文引用。
- 致谢、参考文献标题的四字间距和标题后空一行。
- 附录 A、B、C 连续编号及附录图表公式编号前缀。

## 不能只靠 DOCX XML 下结论的规则

以下内容在标签规范中确实存在，但 `document.xml` 只能提供证据，不能可靠给出最终“对/错”：

1. 表格是否真的跨页、续页是否重复表头、`续表××` 是否位于右上角。
2. 图题是否与图片最终同页、是否紧贴图片下方。
3. 附录、封面、摘要、目录是否实际独立成页。
4. 页码最终显示在哪些物理页面。
5. 浮动图片与题注的最终版面归属。

这些项目应由 LibreOffice/Word 渲染结果提供证据；没有渲染证据时不得伪装成 XML 已经证明的确定错误。

## 规则边界建议

学校硬规则只保留规范文字能够直接证明的项目；扩展诊断单独标记为“图片质量”或“公式质量”，不参与“格式错误”计数，也不自动写成确定性错误批注。这样可以避免系统为了覆盖更多项目而产生超出学校规范的误报。

## 2026-10-10 测试论文复测与 XML 解析修正

对测试目录中 10 篇真实论文进行复测时，排除了 `~$` 开头的 Word 临时锁文件。结果表明：

- 表题或图题与对象之间存在 `w:bookmarkStart`、`w:bookmarkEnd`、`w:proofErr` 或空段落时，原解析器会漏识别题注，进而产生 `TABLE_CAPTION_MISSING` 或 `FIGURE_CAPTION_MISSING`。解析器现已跳过这些不承载正文内容的 XML 节点；遇到有正文的段落仍停止关联，避免跨越真实内容误认题注。
- 表格后的表注同样支持跨越 Word 书签标记，新增了回归测试。表注内容仍要求以“注：”开头。
- `FIG-04` 图片 XML 尺寸/宽高比继续不作为学校格式错误；学校规范没有给出图片宽高比阈值。
- 真实论文中的“表3-1查看……”等题注缺少编号与题名之间的一个空格，属于规范明确要求的真实格式错误；“续表”未右对齐、表号跨章节不连续也保留为错误。
- 重新核对规范原文后确认 `CITE-01` 的“小四号 Times New Roman、上标”有明确依据，因此没有移除引用字号检查。此前仅凭简化审计摘要判断其过严是不正确的。

本轮代码验证：`TableParserTest`、`ImageParserTest` 通过；完整 `mvn verify` 通过。当前批量结果保存在 `artifacts/batch-test-20261010-current`，其中的失败项应按上述规则区分为论文真实不合规与排版引擎无法从 XML 直接证明的项目。

## 2026-10-10 规范 XML 证据边界复核

- 引用格式测试明确覆盖“小四号 Times New Roman、上标”，符合标签规范示例中的 XML 属性；`acceptsSuperscriptCitationSplitAcrossRuns` 应为 `PASS`。正文已出现具体表号的表格引用也应为 `PASS`，由 `acceptsTableReferenceInBody` 覆盖。
- 页码解析读取页脚中现存 `PAGE` 域的居中、字体和字号属性，也读取节的编号格式；它不能仅凭这些 XML 证明页码实际出现在哪些物理页、封面/摘要/目录是否漏出页码，以及正文到附录最终显示是否连续。缺少渲染或完整节映射证据时，不得将这些版面要求直接判为确定错误。
- `EQ-03` 检查公式与编号的最终版面关系。段落级 `w:jc` 只描述段落对齐，不能证明同段公式居中且编号靠右；当前统一返回 `REVIEW`，不能据此写确定错误批注。
- `TAB-04` 当前只读取表头文本。规范也允许单位写在表顶线右侧，因此表头中未识别到单位时只能返回 `REVIEW`；目前尚未抽取表顶线右侧的单位文本，不能把“表头未发现单位”当成缺少单位的证据。
- `EQ-07` 不能只根据“式中/其中”存在就判变量解释完整。OMML 的符号文本可读不等于其语义和逐项定义可证；图片公式、OLE/MathType 对象更无法从外层 XML 读取内部变量。此项应保留为证据不足，不能硬判通过或错误。
- 英文摘要关键词当前检查 `Keywords` 加粗和分隔格式，没有检查显式换行后是否与第一个关键词首字母对齐。显式 `w:br`、制表位和段落缩进可以作为 XML 证据，但自动折行位置取决于字体度量、页面宽度和渲染器；当前检查覆盖不完整，不应报告为已完成。

本轮核对确认引用字号断言和表格引用断言均为 `PASS`。公式对齐方法删除了无效的局部变量，判定行为不变。
