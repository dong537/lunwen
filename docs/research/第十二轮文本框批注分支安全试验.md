# 第十二轮：文本框兼容分支与批注安全

日期：2026-10-07。范围：学校真实模板的文本框 AlternateContent 与批注锚点研究。

模板正文有 72 个 Fallback 文本框段落（Choice 也有对应表示）。测试先在独立 DOM 中选择 Fallback，再计算文本框段落路径；把这个投影路径直接交给原始 XML 写入器时，路径越界并被拒绝。测试没有把失败改成成功，也没有把批注写入任意邻近段落。

这是预期的安全结果：兼容投影会改变兄弟节点结构，且只把批注写进 Fallback 不能证明 Word 选择的 Choice 分支会显示该批注。正式支持文本框必须在“活动分支 + 原始节点 + 输出分支”之间建立可验证映射，并在 Word/WPS 中实机检查；在此之前问题只进入报告。

本轮 Python 批注测试 7 项通过，其中包括正文、表格、重复文字、错误哈希、空段落和文本框投影路径拒绝。没有 Word/WPS/LibreOffice 实机，因此不作编辑器兼容结论。
