# 第七轮：Equation.3 与 MTEF 公式解析

日期：2026-10-04。范围：原件只读、隔离开源能力试验。没有启动公式编辑器、执行嵌入对象或修改论文。

## 关键结论

两个对象都声明 Equation.3，但内部并非同一版本：第一个是 MTEF 5，第二个是 MTEF 3。不能凭 OLE ProgID 推断二进制版本，更不能用正文 run 字号推断公式本体字号。

通过 olefile 读取 Equation Native 流，再调用 transpect 所携 Ruby 解析器，两个载荷均完整解析，未留下未消耗字节。但解析器的字号精度探针失败，且第二个公式缺少显式字体/字号定义，因此当前不能声称旧公式格式能准确无误地检查。

## 真实文件证据

原件 SHA-256 与前轮一致：`3c9c3dc012b779b4ebd20ea35cb86142d73fb911c7733e3b0d1789ce2d6ac2b2`。

| 对象 | OLE 字节 | Equation Native 字节 | 头 / MTEF 载荷字节 | 版本 | 解析器消耗 |
| --- | ---: | ---: | --- | ---: | ---: |
| oleObject1.bin | 3584 | 378 | 28 / 350 | 5 | 350 |
| oleObject2.bin | 3072 | 182 | 28 / 154 | 3 | 154 |

本轮最初将 ZIP 的 embeddings 目录项误送入 OLE 读取器，得到明确错误；随后排除目录项，只检查两个文件。未将失败转换为空结果。

MTEF 5 解析结果包含 5 个字体定义、1 个公式偏好记录、15 个字符记录、4 个模板记录，以及 FULL/SUB 逻辑字号切换。字体定义包含 Times New Roman、Symbol、Courier New、MT Extra，另一个名称原始字节为 `cbcecce5`。最后一个名称未自行猜测编码；JSON 输出保存原始字节和编码标记。

该偏好记录包含 8 项尺寸、30 项间距、12 项样式引用。第一项尺寸为 unit=2、数字半字节序列 [1,2,15]，保留原始记录证据；本轮没有完成每个字符的最终字号推导，不将其直接宣称为全公式统一 12pt。

MTEF 3 解析结果包含 31 个字符记录、2 个模板记录、FULL/SUB 切换；本样本没有 FONT 或 SIZE 记录。只能确认它引用逻辑样式，不能仅凭此载荷确定所有最终字体与绝对字号。原件其他流或指定编辑器环境是否能补足信息，仍需调查。

完整记录保留在本地忽略目录；公开研究证据只记录格式信息、哈希及计数。

## 已复现的精度问题

解析器源码注释规定 SIZE 增量以 1/32pt 表示。本轮构造两个完整、无论文内容的 MTEF 3/5 小样本：增量字段 144，对应 `(144-128)/32 = 0.5pt`。

实测两个版本都输出 0。对应源码对整数执行 `/ 32`，与运行结果一致。探针 `probe_size_precision.rb` 退出 1，保存在 `evidence/size-precision-probe.txt`。第三方库和期望值均未修改，没有通过放宽精度判据使测试转绿。

这两个失败样本不是学校公式本身的字号错误；它们证明该解析器不能不经修复和验证就用于精确字号检测。完整消耗字节也不能证明解释语义正确。

此外，首次 JSON 序列化遇到非 UTF-8 字体名称报错。现改为保留未解码字节，不进行猜测性转码；后续必须结合字符编码记录核实名称。

## 对架构和范围的影响

继续保留 Java/docx4j 为正文解析候选；无需为了两个旧公式将主系统改成 Ruby 或增加独立微服务。

公式处理应区分三层证据：

1. DOCX 层：公式所在段落、编号、对齐、与上下文的关系。
2. 嵌入对象层：OLE 关系、原始部件哈希、MTEF 版本、解析覆盖情况。
3. 公式内部层：记录、字体定义、逻辑样式、尺寸来源及其不确定性。

若后续保留旧解析器，应作为带超时、内存限制的隔离处理进程，并使用固定版本；进入生产前需要修复精度问题、补充缺省信息验证、审计许可证及依赖。这里是候选约束，尚未实现该进程服务。

学校规范未明确公式本体字体、字号时，不新造硬性规则。可验证的外部格式正常检查；内部证据不足时明确显示无法判定，不能显示合规，也不能把“旧公式”本身判为违规。

## 下一研究门

1. 核对学校规范对公式的真实条款，优先验证对齐、编号等有依据的外部规则。
2. 若确需内部字号检查，先用权威格式资料及编辑器控制样本确认尺寸语义，修复上游精度问题并验证，再考虑接入。
3. 对缺少显式字体/字号的 MTEF 3 对象调查其他 OLE 流与编辑器依赖；不能用默认值替代未知。
4. 原始公式的显示尺寸、缩放和最终版式需要指定编辑器或可信渲染对照；本轮没有运行 Word/WPS/LibreOffice。

复现入口：[MTEF 研究目录](../../research-spikes/mtef/README.md)。本轮两个实际解析成功、两个精度探针失败；前轮 docx4j 的 30 项通过不能覆盖这些新失败，不宣称全部能力通过。
