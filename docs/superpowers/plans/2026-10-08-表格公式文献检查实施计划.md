# 表格、公式与参考文献检查实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 DOCX 格式检查内核中增加三线表题头、公式对象与参考文献类别的确定性识别，并生成可回读的 Word 批注。

**Architecture:** 保留现有 `DocxReader → Docx4jDocumentParser → RuleEngine → InspectionService → CommentWriter` 数据流。解析器新增表格、公式、参考文献索引；规则引擎只消费结构模型；报告扩展对象摘要和需复核信息；批注 writer 使用段落或表格 XML 路径作为锚点。

**Tech Stack:** Java 21、Spring Boot、docx4j 17.2.1、JAXB、DOM XML、JUnit 5、React + TypeScript。

## Global Constraints

- 边距继续按 1474 twips（2.6 cm）执行。
- 不实现登录、注册、教师端和学生端。
- 不修改公式、表格内容和参考文献原文，只新增批注与高亮。
- 无法由 XML 证明最终视觉位置时返回需复核，不直接判定错误。
- MathType/OLE 只识别存在性和位置，不做无损转换。
- 同一段落或同一表格同一规则只生成一条批注。
