# 单机检测 API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为现有 DOCX 检测内核提供无需登录的同步 HTTP 上传、JSON 报告和批注副本下载能力。

**Architecture:** Spring Boot Web 只负责 HTTP 边界；`InspectionService` 编排临时文件、`InspectionKernel`、`JsonReportWriter` 和 `CommentWriter`。所有检测结论仍由现有规则模块产生。

**Tech Stack:** Java 21、Spring Boot 3.4.3、Maven、docx4j 17.2.1、Jackson、JUnit 5、MockMvc。

## Global Constraints

- 不实现登录、注册、账户、权限和数据库。
- 上传文件必须是 `.docx`，大小限制由配置控制，错误不能静默转为空结果。
- 原始文档只读，所有结果绑定源文件 SHA-256。
- `REVIEW`、`UNKNOWN`、`UNSUPPORTED` 必须原样返回。
- API 测试使用真实生成的 DOCX，不使用 mock 数据伪造检测成功。
