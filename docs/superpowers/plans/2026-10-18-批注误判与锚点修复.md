# 批注误判与锚点修复

## 目标与边界

修复雷家琪论文中由分页符和批注偏移映射导致的错误判定/高亮，并修正文案与规则相反的问题。DOCX XML 是格式证据的唯一来源；本次不改变学校格式要求，也不将不符合精确数值的缩进放宽为通过。

本轮继续处理用户反馈的批注范围和空白诊断：字符级间距错误只标出错误字符；段落首行缩进作为段落格式问题说明，不描述成手动空格错误；英文关键词加粗错误只标注 `Keywords` 标签之后实际加粗的部分。将泛化格式建议替换为明确指出格式项和应改值的建议。

明确不做：不把全文空格都判错；不改变学校规范；不放宽首行缩进或其他精确匹配标准；不覆盖现有批注文件。

## 数据与模块约定

- `Docx4jDocumentParser` 输出段落内可见文字；分页符和分栏符不计入可见文本，手动换行和制表符保留。
- `RunModel.source` 使用所在段落路径，`start/end` 是段落可见文本中的半开 UTF-16 区间；段落级来源覆盖整段可见文本。
- 规则模块只依据解析器提供的可见文本与 OOXML 格式证据判定。标题格式不检查仅包含换行控制符的 run。
- `CommentWriter` 按同一可见文本顺序把错误区间映射到 XML run；Word 批注锚点保持段落级，高亮只着色命中区间的文字 run。
- 字符类空白规则使用段落内 UTF-16 半开区间；解析器输出的段落/运行来源与规则错误范围必须使用同一坐标系。缺少空白或纯 OOXML 属性错误没有可染字符时，仅保留批注锚点，不扩展高亮范围。
- 修改建议由规则结果的原因码决定，避免“要求一格却建议两格”或“冒号已加粗却建议再加粗标签”。

## 成功标准与验证

- 回归测试证明分页符不污染标题文字/字号，手动换行仍保留。
- 回归测试证明不同 run 的段落偏移连续，高亮仅覆盖错误 run。
- 回归测试证明目录、章节标题、参考文献、摘要标签和图表题的多余/异类空白只高亮错误字符；首行缩进错误不会被描述或呈现为手动空格错误。
- 回归测试证明 `Keywords` 与后续文字位于同一 run 时，正确加粗的标签不会被错误高亮，批注只指出冒号、空格或关键词正文中实际不符合要求的部分。
- 已知格式错误的建议文案必须直接写明格式项、实际问题和应改值，不使用“按规范修改并与同级一致”等泛化建议。
- 回归测试证明缩进结果同时报告段落缩进与文字前空格，并且仍按精确值判定。
- 对原始论文重新运行检查与批注，核对误报消失、真实错误及其批注保持正确。
- 运行相关 Maven 定向测试和全量测试；记录既有失败，不以局部通过替代全量结果。

## 本轮发现的共性误判

- 封面字段可能位于表格单元格。封面结构边界仍排除表格中的摘要/章节信号，但字段收集必须包含已确认封面范围内的表格段落。
- 封面类型文字出现在普通表格时，不应单独启动整套封面格式检查；只有封面区域中的独立标题可启动检查。启动后，封面表格中的独立字段和日期仍应检查。
- 规范只明确二级标题使用 1.5 倍行距。一级、三级标题没有对应行距硬规则，不能因现有 XML 行距不同而报错。
- 批注定位按解析器的可见文本坐标计算。删除修订、移动修订及超链接等嵌套 run 必须与解析器采用一致的可见文本遍历；无法精确定位时应明确不写入该批注，不得退化为整段高亮。
